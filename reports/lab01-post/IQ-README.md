# بازتولید تحلیل ضبط‌های آزمایش اول

۲۲ فایل اصلی از پوشهٔ محلی `Lab1/recordings` تحلیل شده‌اند. نام، مرکز RX، نرخ، بهره و زمان از نام فایل آمده‌اند؛ این تنظیمات اسمی‌اند. هر نمونه دو float32 با ترتیب I,Q و little-endian است (۸ بایت). هیچ نمونه یا اندازه‌گیری شبیه‌سازی‌شده‌ای جای دادهٔ خام قرار نگرفته است.

## اجرا از ریشهٔ مخزن

```text
python -m pip install numpy scipy matplotlib
python code/lab01/session_analysis.py --recordings "C:/Users/LENOVO/Desktop/Daneshgah/SDRLab/Lab1/recordings"
```

روی رایانهٔ دیگر، مسیر آخر را به پوشهٔ نسخهٔ خام تغییر دهید و SHA-256 را با manifest تطبیق دهید. کد به رادیو وصل نمی‌شود. به علت حجم زیاد فایل های IQ تنها دو فایل به عنوان نمونه بارگزاری شده اند. حجم کل ۲۲ ضبط اصلی ۱٬۴۱۹٬۸۰۰٬۵۷۶ بایت است؛ برای بازتولید همهٔ تحلیل‌ها، سایر ضبط‌های اصلی نیز لازم‌اند.

خروجی: `data/lab01/session/results.json` و `manifest.json` و شش تصویر در `assets/images/lab01/iq`. نسخهٔ PDF و HTML از `content/lab01/post.json` ساخته می‌شود؛ اجرای تحلیل، متن علمی را خودکار تغییر نمی‌دهد.

## تعریف اندازه‌گیری و محدودیت‌ها

- Welch: Hann، هم‌پوشانی ۵۰٪ و میانگین خطی؛ FFT برابر 16384 در 20 MS/s و 8192 در 2.6 MS/s. قاب ناقص انتهایی در Welch حذف و در آبشار با پُرکردن صفر حفظ می‌شود.
- B99 در ROI مشخص با نویز موجود؛ Bx بیرونی‌ترین عبورهای آستانهٔ طیف بیشینه است و با پهنای متصل به قله تفاوت دارد. هر دو خروجی ذخیره می‌شوند. x از معیار قله/کف طیفی انتخاب شده؛ SNR انتگرالی نیست.
- پهنای رویداد فراسو روی زمان فعال 56.1 تا 61.2 ms محاسبه شده؛ شکل کل ضبط را نمایش می‌دهد. خطوط باریک پایدار در باند هم وجود دارند.
- ریموت نزدیک لبهٔ باند است. فیلتر کانال 80 kHz، گام توان 0.1 ms، آستانه‌های −58، −55 و −52 dB و فاصلهٔ ادغام 8 ms به‌کار رفته‌اند. آخرین گروه نزدیک لبهٔ فایل از آمار مدت کامل حذف شده است؛ این گروه‌ها بستهٔ رمزگشایی‌شده نیستند.
- ppm به تشخیص FCCH و شبکهٔ GSM مشروط است؛ SCH/BCCH بازیابی نشده است. پراکندگی برست‌ها عدم قطعیت کل نیست.
- cf32 timestamp یا شمارندهٔ سخت‌افزار ندارد؛ استفاده از همهٔ نمونه‌های فایل، اثبات پیوستگی دریافت شبکه نیست. شمار فشار دکمهٔ ریموت ثبت نشده است.
- فایل‌های حلقهٔ پایه و جابه‌جایی LO تن‌های متفاوت 250 و 300 kHz نسبت به TX اسمی دارند؛ تنظیم TX هم‌زمان ذخیره نشده است. اختلاف آن‌ها خطای فرکانسی مرجع محسوب نشده است.
