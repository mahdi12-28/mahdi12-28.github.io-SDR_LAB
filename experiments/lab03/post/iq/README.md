# ضبط‌های I/Q

فایل‌های اصلی و فرادادهٔ هر ضبط را در این پوشه بگذارید و نام اصلی آن‌ها را حفظ کنید؛ نام استاندارد `lab02` در ضبط‌ها با شمارهٔ آزمایش سوم در سایت تعارض ندارد.

1. در `../data/iq_manifest.json`، مسیر `path` را مانند `iq/نام-واقعی-ضبط.cf32` پر کنید.
2. فرمت و نرخ واقعی فایل را کنترل کنید؛ پیش‌فرض `cf32_le`، یعنی I و Q از نوع float32 مختلط با ترتیب little-endian و نرخ 240000 نمونه در ثانیه است. برای int16 از `ci16_le` استفاده کنید.
3. `dev_hz`، بهره و بازهٔ تحلیل را مطابق همان ضبط قرار دهید. اگر کانال جابه‌جا است، `frequency_shift_hz` را با علامت جابه‌جایی مشاهده‌شده وارد کنید.
4. برای تفریق نویز، `noise_path` و `noise_rf_gain_db` را فقط برای ضبط نویز با همان نرخ، بهره، فیلتر و تنظیمات وارد کنید. خروجی بدون این گزینه B99 کل توان سیگنال و نویز در بازهٔ انتخاب‌شده است.
5. از پوشهٔ `post` اجرا کنید:

```bash
python -m pip install -r code/requirements.txt
python code/analyze_iq.py
```

نتایج عددی و نمودارها در `data/iq_results.json` و `iq/analysis/` ذخیره می‌شوند. جدول و پخش‌کنندهٔ صوت در نسخهٔ وب خودکار فعال می‌شوند. سپس برای هماهنگی PDF، `python code/build_report.py` و `python code/render_pdf.py` را اجرا کنید.

صدای بازتولیدشده برای پخش نرمال می‌شود؛ بلندی فایل WAV معیار مقایسهٔ مطلق بهره یا SNR نیست. نمودارهای نظری گزارش با برچسب نظری مستقل می‌مانند.
