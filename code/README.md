# کدهای دریافت

دو فایل این پوشه قالب آموزشی بازنویسی‌شده از صفحات ۶ و ۱۰ دستورکار هستند. این فایل‌ها کد اصلی جلسه نیستند و در این محیط به سخت‌افزار متصل نشده‌اند. هیچ کد ارسال RF در آن‌ها وجود ندارد.

کد اصلی پایتون و MATLAB خودتان را همراه با نسخهٔ وابستگی‌ها، فایل‌های واقعی GRC و لاگ جلسه اضافه کنید و لینک‌های بخش «فایل‌ها» را در `tools/build.py` به آن‌ها متصل کنید.

برای اجرای قالب پایتون، در محیط دارای libiio بومی و pyadi-iio، NumPy و Matplotlib:

```bash
python code/pluto_receive_template.py
```

برای ذخیرهٔ یک برداشت **جدید** با فایل خام و فراداده:

```bash
python code/pluto_receive_template.py --team YOURTEAM --save-dir data
```

فایل برداشت جدید را به‌جای دادهٔ جلسهٔ گذشته معرفی نکنید. نمودار نمونه، قدرمطلق FFT با مقیاس نسبی است و کالیبراسیون توان یا تخمین PSD ندارد.
