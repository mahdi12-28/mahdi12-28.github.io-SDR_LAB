# فلوگراف اصلی جلسه

در ZIP تصاویر، فایل `.grc` وجود نداشت. فایل واقعی ذخیره‌شده در جلسه را در این پوشه قرار دهید و در بخش فایل‌ها به آن لینک بدهید. برای اصالت مدارک، فلوگرافی با عنوان «فایل اصلی جلسه» از روی عکس بازسازی نشده است.

طبق صفحات ۷ و ۹ دستورکار، مستندات باید بلوک‌های PlutoSDR Source و QT GUI Frequency Sink، نشانی `ip:192.168.1.10`، فرکانس ۹۴۵ مگاهرتز، نرخ ۲٫۶ مگاسمپل‌برثانیه، پهنای باند ۲ مگاهرتز و بهرهٔ دستی ۲۰ دسی‌بل را نشان دهند. پارامترهای واقعی اجرای خودتان را گزارش کنید.
