# فلوگراف آزمایش صفر؛ مسیر دوم

[دریافت Lab00App2.grc](Lab00App2.grc) · [بخش مسیر دوم در گزارش](../reports/lab00/index.html#windows)

فایل ارائه‌شدهٔ تیم بدون تغییر بارگذاری شده است. آن را با GNU Radio Companion باز کنید؛ نسخهٔ ثبت‌شده در فرادادهٔ فایل `3.10.12.0` است. به بلوک‌های PlutoSDR از مجموعهٔ IIO و نمایشگر QT GUI نیاز دارد.

## تنظیمات ذخیره‌شده

| مورد | مقدار |
| --- | --- |
| اتصال | PlutoSDR Source → QT GUI Frequency Sink، دادهٔ مختلط |
| URI منبع | `192.168.1.10` |
| فرکانس منبع | `945000000 Hz` |
| نرخ نمونه‌برداری منبع | `2600000 sample/s` |
| پهنای باند منبع | `2000000 Hz` |
| حالت / بهره | دستی / `20 dB` |
| اندازهٔ بافر | `32768` نمونه |
| متغیر samp_rate | `20000000` |
| مرکز محور نمایش | `90000000 Hz` |
| پهنای محور نمایش | `samp_rate`، برابر `20000000 Hz` |
| اندازهٔ FFT / پنجره | `1024 / Blackman–Harris` |

## پیش از اجرا

مرکز و پهنای محور Frequency Sink در فایل ذخیره‌شده با تنظیمات منبع یکسان نیستند. برای محور متناظر با منبع، مرکز نمایش را `945e6` و پهنای آن را `2.6e6` قرار دهید؛ می‌توانید نرخ منبع و پهنای نمایش را به یک متغیر مشترک با مقدار `2.6e6` متصل کنید. مقدار فعلی `samp_rate` نرخ منبع را کنترل نمی‌کند.

URI ذخیره‌شده فاقد پیشوند `ip:` است؛ آن را در نصب خود بررسی و در صورت نیاز به `ip:192.168.1.10` تغییر دهید. تغییرهای پیشنهادی روی فایل بارگذاری‌شده اعمال نشده‌اند. اجرای سخت‌افزاری این فایل در این به‌روزرسانی آزموده نشده است.
